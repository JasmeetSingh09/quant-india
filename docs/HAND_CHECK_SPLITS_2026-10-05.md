### Defects found along the way (proposals, not fixed)

1. **Two dividends on one exchange line keep only the first amount.** Up to 279 stored dividend rows
   read like "Final Dividend Rs 8 / Special Dividend Rs 67", and the stored amount is the first number
   only. Examples: TCS 2023-01-16 stored Rs 8 (paid Rs 75); TCS 2025-01-17 stored Rs 10 (paid Rs 76);
   NESTLEIND 2019-08-09 stored Rs 23 (paid Rs 203); SWELECTES 2012-07-17 stored Rs 3 (paid Rs 123).
   A few rows (ITC "including special", InvIT distributions) must not be summed. Proposed fix: sum the
   per-share dividend amounts on a line, skip "including" phrasing and unit distributions, then re-parse.
   That changes stored values, so it needs a conflict-resolving re-parse, not the additive one.
2. **"Fv Splt Frm" lines are not parsed.** Most already have a Yahoo twin; ALANKIT and LTFOODS did not.
   If the parser learns this wording, the re-parse must not add a second split beside an existing
   Yahoo or hand-verified row for the same event.
3. **Rights issues are not adjusted.** 320 stored lines mention rights; deep-discount ones (such as
   HERITGFOOD's at face value) move the price like a bonus. A rights rule needs the issue price and
   the ratio.
